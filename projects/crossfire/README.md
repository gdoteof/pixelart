# Crossfire

Tucker Carlson vs. Jon Stewart, back on the CNN Crossfire set where Stewart told him to stop hurting
America in 2004. The occasion: Tucker's 2026 break with Trump, and Stewart's renewal through 2028.

- Song: `lyrics.txt` + `style.txt` -> `python -m pixelart.song.generate`, then `pick`. Or bring one with `pick PROJECT file.wav`. `audio/` is not committed.
- Look: native resolution, palette, reference art
- Render: `uv run python -m pixelart.render projects/NAME`
